## 구현 내용

남은 MVP 항목을 Workspace, 협업, 저장/복구, AI proposal, 검증 순서로 마무리했다.

주요 추가/수정:

- Workspace: `StorageProvider` read/write metadata, server provider, root 입력, 파일 tree, 선택/이전/다음/저장 UI
- 협업: Yjs document wrapper, CodeMirror `Y.Text('source')` extension 연결, Hocuspocus server/client, awareness presence panel, IndexedDB persistence
- 저장/복구: Markdown block read/write-back, sourceHash stale metadata, 저장 후 target hash 갱신, workspace root path escape 방어
- AI proposal: `diff` 기반 proposal model, unified diff preview, mock AI generate/apply/cancel UI
- E2E: Playwright가 Vite와 Hocuspocus를 함께 띄우고 두 browser context 동기화를 검증

## 테스트 케이스

- AI proposal model: diff 생성, exact base 적용, stale source 실패, Mermaid mock proposal 생성
- Proposal UI: generate, diff preview, apply, cancel
- Server storage: file read/write, Markdown block stale 상태, path escape 차단, Hono API 응답
- Collaboration: Yjs update clone, room id, presence 색상, disk persistence, Hocuspocus server factory, collaboration panel
- Playwright: workbench smoke, template/export, preview controls, editor typing/render, tool drag/drop, AI proposal apply/render, two-session collaboration sync
