## 구현 내용

제품 SPEC과 MVP 작업 계획을 작성했다.

SPEC에는 다음 내용을 포함했다.

- 제품 목표와 사용자
- 핵심 사용 흐름
- MVP 범위와 제외 범위
- 기능/비기능 요구사항
- 데이터 모델
- 모듈 구조
- dialect adapter 인터페이스
- UX 원칙
- 검증 기준
- 열린 질문

작업 계획에는 다음 마일스톤을 포함했다.

- M0 문서와 기준 정리
- M1 앱 스캐폴딩
- M2 단일 사용자 편집기/뷰어
- M3 편집 생산성 기능
- M4 협업 기반
- M5 저장과 복구
- M6 AI 제안 설계
- M7 검증과 정리

## 검증

- 요청, SPEC, 작업 계획, 구현 문서가 서로 링크되어 있다.
- 작업 계획은 체크리스트와 완료 기준을 포함한다.
- SPEC은 구현자가 다시 읽고 앱 구조를 재구성할 수 있는 수준의 요구사항과 인터페이스를 포함한다.

## 남은 결정

SPEC의 열린 질문을 구현 전에 결정해야 한다.

- 첫 배포 형태: 정적 SPA 또는 협업 서버 포함 full-stack
- 인증 범위: 익명 room 또는 계정 기반
- AI 연동 방식: mock 우선 또는 OpenAI API 직접 연동
