## 구현 내용

Flowchart preview SVG에서 node를 직접 선택해 edge를 연결하는 interaction을 추가했다.

추가/수정:

- `src/App.tsx`
  - Edge 설정 상태를 App으로 lift
  - Tools Edge 활성 상태, preview node 선택, Structure Edge form을 같은 draft에 연결
  - preview node 클릭 2회 또는 drag 완료 시 `addFlowchartEdge`로 source에 edge 추가
- `src/components/preview/DiagramPreview.tsx`
  - Mermaid SVG node group에 `data-flowchart-node-id` 부여
  - Edge mode에서 node 클릭을 source/target 선택으로 전달
  - node drag 중 preview overlay line 렌더링
  - overlay line style을 Edge type/label에 맞춰 표시
- `src/components/structure/FlowchartStructurePanel.tsx`
  - Edge 설정을 controlled draft로 받을 수 있게 변경
  - preview click/drag 결과가 Edge source/target/type/label에 반영되도록 동기화
- `src/components/tool-palette/ToolPalette.tsx`
  - Edge tool active 상태 표시
- `src/diagram/flowchart-structure.ts`
  - 공유 Edge draft type 추가
- `src/styles.css`
  - Edge mode cursor, preview node hover, drag overlay line style 추가
- `tests/e2e/app.spec.ts`
  - Edge tool 선택, preview node 클릭 연결, preview node drag 연결 검증 추가
