## 구현 내용

테스트 라이브러리 선정 내용을 문서에 확정하고, jsdom 기반 컴포넌트 테스트와 render pipeline 테스트를 추가했다.

추가한 테스트 도구:

- `@testing-library/react`
- `@testing-library/user-event`
- `@testing-library/jest-dom`
- `jsdom`

추가/보강한 테스트 케이스:

- Mermaid dialect detection과 empty source diagnostic
- render state success/error 변환
- Markdown fenced diagram block 추출과 export
- diagram file extension filter
- diagnostics panel success/error 표시
- workspace file 선택 콜백과 확장자 표시
- toolbar template 선택, SVG export enabled/disabled, Markdown import
- tool palette click 삽입
- preview error/success 상태와 zoom/pan control wiring
