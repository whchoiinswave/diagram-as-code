## 구현 내용

Vite React TypeScript 앱을 생성하고 단일 사용자 Mermaid 편집기를 구현했다.

포함한 기능:

- Vite, React, TypeScript, ESLint, Vitest 설정
- CodeMirror 기반 source editor
- Mermaid dialect adapter와 render state machine
- debounce 기반 preview 렌더링
- render diagnostics panel
- Mermaid 템플릿 선택
- SVG export
- Markdown fenced code block import/export
- localStorage draft persistence
- Embedded Editor Mode 컴포넌트
- Workspace shell, 파일 목록 패널, 우측 아이콘 tool palette
