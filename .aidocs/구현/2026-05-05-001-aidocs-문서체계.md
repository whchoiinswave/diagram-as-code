# IMPL-20260505-001 AI 문서 체계 구현

## 관련 요청

- [REQ-20260505-001 프로젝트 목표와 문서 체계](../요청/2026-05-05-001-프로젝트-목표와-문서체계.md)

## 구현 내용

프로젝트 폴더를 `mermaid-editor`에서 `diagram-as-code`로 변경하고 `.aidocs` 문서 구조를 만들었다.

```text
.aidocs/
  README.md
  지식/
  요청/
  구현/
  임시/
  할일/
```

초기 문서로 프로젝트 원칙, 사용자 요청, 구현 기록, 실행 계획, 임시 메모 규칙을 추가했다.

## 문서 작성 규칙

- 요청이 들어오면 `요청/`에 `REQ-YYYYMMDD-NNN` 문서를 만든다.
- 구현 전에 필요한 작업은 `할일/`에 `TODO-YYYYMMDD-NNN`으로 기록한다.
- 구현 완료 후 `구현/`에 `IMPL-YYYYMMDD-NNN` 문서를 만들고 변경 파일, 동작, 검증 결과를 적는다.
- 완료된 요청과 할일은 관련 구현 문서를 링크한다.
- 임시 조사나 중간 메모는 `임시/`에 두고, 오래 보존할 내용은 `지식/` 또는 `구현/`으로 승격한다.

## 검증

- `.aidocs` 기본 구조가 생성되었다.
- 초기 요청, 원칙, 실행 계획, 구현 기록이 서로 링크되어 있다.

## 남은 위험

앱 코드가 아직 없으므로 기술 스택, 렌더링 방식, AI 통합 방식은 다음 구현 요청에서 확정해야 한다.
