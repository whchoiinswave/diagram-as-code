# REQ-20260506-013 Preview Edge 연결

## 상태

완료

## 요청

Flowchart에서 Tools의 Edge를 선택한 뒤 뷰어 쪽 노드를 클릭하거나 드래그해서 edge를 연결할 수 있어야 한다.

- 노드 클릭은 `from`, `to` 선택으로 동작한다.
- 노드 드래그는 드래그 중 마우스 좌표에 따라 임시 라인이 늘어나거나 줄어든다.
- 임시 라인의 스타일은 우측 Edge 설정의 type/label을 따른다.
- 뷰어에서 클릭한 노드는 우측 Edge 설정의 source/target select에 동기화된다.

## 결정

- Mermaid SVG 내부 node group에 `data-flowchart-node-id`를 부여해 preview interaction target으로 사용한다.
- Panzoom과 충돌하지 않도록 Edge mode에서는 preview surface가 pointer capture 단계에서 이벤트를 받는다.
- Edge 연결 완료 시 Mermaid source 마지막에 edge 문법을 추가한다.
