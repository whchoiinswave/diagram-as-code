# REQ-20260506-012 Flowchart 구조 편집

## 상태

완료

## 요청

우측 뷰어에서 자유 위치 조정보다는 제한적인 구조 편집을 진행한다. 노드 추가는 source 마지막에 노드 선언을 추가하는 방식으로 처리하고, edge는 노드와 노드 사이 연결로 추가한다. 결정 분기 같은 shape는 Tools에 개별로 두고, 기존 노드의 shape/label 변경도 가능하게 한다.

추가 요청:

- Tools의 Edge 아이콘만으로는 라인을 이을 수 없으므로, UI에서 edge의 source/target/type/label을 명시적으로 설정할 수 있어야 한다.

## 결정

- Mermaid 자동 레이아웃과 충돌하는 좌표 편집은 구현하지 않는다.
- Flowchart 전용 얕은 parser로 node, edge, shape, label, source line 위치를 추출한다.
- Tools는 shape별 node snippet을 생성하고, Structure 패널은 node 변경과 edge 연결을 담당한다.
- Flowchart의 Edge tool 클릭은 임의 edge source를 삽입하지 않고 Structure 패널의 Edge 설정으로 포커스 이동한다.
