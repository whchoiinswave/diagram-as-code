# REQ-20260505-004 편집 모드와 협업 기준 구체화

## 상태

완료

## 요청

제품 요구사항을 다음 방향으로 구체화한다.

- 단일 편집기만 제공하는 외부 사이트 삽입용 모드가 필요하다.
- 자체 스토리지 경로를 입력받아 하위 폴더의 관련 확장자 파일을 목록화한다.
- 좌측 트리에서 파일을 보여준다.
- 화살표, 위/아래 키, 마우스 클릭으로 파일을 순회하고 선택할 수 있다.
- 선택된 파일은 우측 넓은 패널에서 편집한다.
- 편집 보드와 다이어그램이 클 경우 손모양 이동 모드가 필요하다.
- 편집 도구는 우측 도구 패널에 아이콘으로 표시한다.
- 도구는 drag/drop으로 쉽게 추가할 수 있어야 한다.
- 여러 사용자가 동시에 편집하는 기준이 필요하다.
- 서버에서 웹 편집기를 띄울 때 특정 diagram 영역을 자동으로 열고 동시 편집할 수 있어야 한다.

## 결정

- 제품 모드를 `Embedded Editor Mode`, `Workspace Editor Mode`, `Server Collaboration Mode`로 나눈다.
- storage 접근은 `StorageProvider`로 추상화한다.
- 협업 단위는 파일 전체 또는 Markdown 내부 diagram block을 가리키는 `DiagramTarget`이다.
- 서버는 `LaunchContext`로 workspace, file, diagram block, room id를 편집기에 전달한다.
- tool palette의 drag/drop 결과는 시각 객체 저장이 아니라 dialect별 source snippet 삽입으로 처리한다.
