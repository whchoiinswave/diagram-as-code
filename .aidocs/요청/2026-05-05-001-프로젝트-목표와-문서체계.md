# REQ-20260505-001 프로젝트 목표와 문서 체계

## 상태

완료

## 요청

diagram 편집기를 목표로 잡고 실행 계획을 세운다. 문서 위치는 `.aidocs`로 하며 다음 구조를 사용한다.

- 지식: 핵심 원칙, 구현 방향성. 초기 업데이트 이후 자주 업데이트하지 않는 문서
- 요청: 사용자 요청. 각 번호를 매겨 구현과 연계하고 완료 체크
- 구현: 실제 구현 문서. 재구현 가능한 기능 단위 설명
- 임시: 구현에 필요한 메모와 임시 저장소
- 할일: 이슈와 할일. 날짜와 번호를 붙이고 완료 시 구현 문서와 연결

추가로 필요한 문서 요소가 있는지 검토한다.

## 결정

- 폴더명은 Mermaid 전용보다 넓은 범위를 담기 위해 `diagram-as-code`로 변경한다.
- `.aidocs` 아래 5개 기본 폴더를 만든다.
- 추가 폴더는 만들지 않고 결정 기록, 검증 기록, 용어집, 색인은 기존 구조 안에서 관리한다.
