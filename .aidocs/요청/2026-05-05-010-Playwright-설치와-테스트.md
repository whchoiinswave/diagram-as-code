# REQ-20260505-010 Playwright 설치와 테스트

## 상태

완료

## 요청

Playwright를 설치하고 브라우저 테스트를 진행한다.

## 결정

- `@playwright/test`를 dev dependency로 추가한다.
- Chromium 프로젝트만 먼저 구성한다.
- Playwright webServer는 기존 `localhost:5173` 서버를 재사용하고, 없으면 `npm run dev -- --port 5173 --strictPort`로 띄운다.
- E2E 결과물은 `playwright-report`, `test-results`로 생성되므로 git ignore에 추가한다.
