# AI Docs

이 디렉터리는 diagram 편집기 프로젝트의 작업 기억이다. 목표는 대화에서 나온 요청, 실제 구현, 남은 할일, 핵심 지식을 서로 연결해서 나중에 다시 읽어도 재구현 가능한 상태를 유지하는 것이다.

## 구조

- `지식/`: 핵심 원칙, 구현 방향성, 용어, 장기적으로 자주 바뀌지 않는 기준
- `요청/`: 사용자 요청 기록. 요청마다 번호를 붙이고 구현/할일 문서와 연결
- `구현/`: 실제 구현 결과. 기능 단위로 재구현 가능한 설명과 파일 경로 기록
- `임시/`: 구현 중 메모, 조사 결과, 버릴 수 있는 중간 산출물
- `할일/`: 이슈와 작업 목록. 날짜와 번호를 붙이고 완료 시 구현 문서와 연결

## 번호 규칙

- 요청: `REQ-YYYYMMDD-NNN`
- 할일: `TODO-YYYYMMDD-NNN`
- 구현: `IMPL-YYYYMMDD-NNN`
- 지식: `KNOW-NNNN`

하나의 요청은 여러 할일과 구현 문서에 연결될 수 있다. 완료된 할일은 반드시 관련 구현 문서를 링크한다.

## 필요한 추가 요소

현재 5개 구조면 충분하다. 다만 폴더를 늘리기보다 아래 항목을 기존 폴더 안의 문서 섹션으로 관리한다.

- 결정 기록: 중요한 기술 선택은 `지식/` 또는 관련 `구현/` 문서에 `결정` 섹션으로 남긴다.
- 검증 기록: 테스트, 수동 확인, 남은 위험은 `구현/` 문서의 `검증` 섹션에 남긴다.
- 용어집: DSL, renderer, dialect 같은 반복 용어는 `지식/`에 모은다.
- 색인: 전체 문서 탐색은 이 `README.md`에서 관리한다.
